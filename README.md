# PrettyCSV

A single-file, no-install CSV viewer that turns a CSV into a clean, formatted table. Everything runs in your browser; your data never leaves your machine.

Open `index.html` in any browser, then drop in a CSV (or paste one, or try the sample).

## Features
- **Look:** 7 themes, light/dark toggle, header styles, fonts, text size, spacing, zebra stripes, gridlines, shadows
- **Formatting:** per-column rename, hide, align, type, number/currency/percent/date formats, data bars, heat maps, badges, totals row
- **Views:** sortable, searchable, paginated table, or a **Zephyr Scale** test-case view
- **Export:** CSV, JSON, Excel (.xlsx), Zephyr Scale import CSV, styled HTML, print/PDF, copy as TSV

No dependencies, no build step.
